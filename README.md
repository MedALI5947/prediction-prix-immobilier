# Prédiction du prix de vente de maisons

## Objectif

Ce projet de régression vise à estimer le prix de vente d’une maison
(`SalePrice`) à partir des caractéristiques du bien.

## Démarche prévue

1. Explorer et préparer les données du défi Kaggle.
2. Comparer un modèle de régression à une référence qui prédit le prix médian.
3. Mesurer l’erreur absolue moyenne (MAE) sur un jeu de validation.
4. Créer une interface Streamlit pour saisir les caractéristiques d’une maison
   et afficher une estimation.

Projet en cours de développement.
